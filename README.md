# Karma Website

## Project Description

This is my personal website project created and deployed using AWS EC2.

## Technologies Used

- HTML
- CSS
- Apache2 Web Server
- AWS EC2
- GitHub
- HTTPS / SSL

The website is hosted on an AWS EC2 Ubuntu server using Apache2.
